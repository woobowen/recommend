## 参照来源与解释

- [TIGER 原论文 Table 1](https://arxiv.org/html/2305.05065)：Sentence-T5 + RQ-VAE。
- [GRID 论文 Table 1](https://arxiv.org/html/2507.22224)：默认 Flan-T5-XL + RK-Means。
- GRID 最高列取表1–8每项测试指标的最大值，均出自表2。Sports/Toys 为 Flan-T5-XXL；Beauty Recall@5 为 Large/XXL 并列、Recall@10 为 XXL、NDCG@5/@10 为 Large。Beauty 最高列不是同一实验行。
- 本次为单个种子运行，按验证 Recall@5 选择 checkpoint；GRID 报告五个种子的平均结果。不同配置的数值差异不能直接证明统计显著提升。
