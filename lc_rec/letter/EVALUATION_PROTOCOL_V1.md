# Instruments / frozen Beam20 offline evaluation v1

Machine definition: [a0_evaluation_v1.json](config/a0_evaluation_v1.json). This version freezes formulas and the Instruments user/item/SID axes. The current executable additionally pins the A0 RUN and prediction hashes. Future A1/Shuffle must bind their own RUN/prediction manifests while preserving this protocol; no A1/Shuffle execution is authorized here.

1. **Paper layer:** raw decoded text → last `Response:` segment → strip → remove literal spaces. Stable descending original sequence score, ties retain generation order. All twenty candidates remain, including invalid and repeated SIDs. Complete SID equality determines relevance. Single-target HR equals Recall. NDCG adds *every* matching position's discount, including repeated target SIDs.
2. **Extended layer:** HR at 1/5/10/20, NDCG at 5/10/20, MRR at 5/10/20. MRR uses only the first target occurrence. SID validity uses frozen full-SID catalog membership. Duplicate occurrences equal K minus unique strings, including invalid strings. Coverage is unique valid SIDs across users divided by 9,897, never 9,922 items. First-hit histogram partitions all 24,772 users.
3. **CCE/statistics layer:** an additional evaluation of the unchanged ranked SID output. It does not identify which colliding item the model intended, change SID assignments, perform ZCR, or modify the original metrics.

CCE basis is [paper v2 §3.1, equations 4–7 and Figure 2](https://arxiv.org/html/2605.25330v2), checked against [official code at 6dd5d314f62d3379e664a52c9007e7645556970c](https://github.com/Nishikata97/CollisionGenRec/blob/6dd5d314f62d3379e664a52c9007e7645556970c/model/cce.py). Original bytes and MIT license are preserved [here](review/final_audit_20261113/external/source_identity.json).

For the first target occurrence, let P be the sum of preceding group sizes, and g the target group size. The paper's one-based starting position is p=P+1. Let m=min(g,max(0,K-P)). Then ItemHit=m/g; ItemNDCG=sum(i=1..m,1/log2(P+i+1))/g. An absent target receives zero. Unknown SID groups occupy one position, following official `.get(sid,1)`; preceding duplicate occurrences each expand, while target credit uses its first occurrence only. With unique valid SIDs throughout the relevant prefix and a single target occurrence, CCE reduces to SID-level scores. A unique target alone is insufficient for this reduction if preceding SIDs collide.

Supplementary groups are fixed before prediction-performance calculation: visible test history is `items[:-1][-20:]`, bins 0–5/6–10/11–20. Popularity counts every original `items[:-2]` occurrence once, without SeqRec prefix multiplicity. Positive-frequency catalog tertiles use nearest ranks ceil(n/3),ceil(2n/3); equal frequencies stay together. Zero-frequency items form UNSEEN. No validation/test targets enter frequency counts. These are exploratory internal definitions, not LETTER published subgroup results.

Overall user bootstrap uses PCG64 seed 20261113, 5,000 replacement samples of 24,772 users, replicate-major int64 draws, linear 2.5/97.5 percentiles. It measures uncertainty conditional on the fixed trained model, not variation across training seeds. The global intervals are not subgroup intervals. Each subgroup retains its sample denominator; small UNSEEN results are descriptive and unstable.

Server CSV keeps row_idx, axis hash, target identities, group fields, first target rank (0=miss), generation time and sixteen metric columns, with no copied candidate text. Companion NPZ contains float64 matrix, column keys and row_idx. Its SHA and the CSV SHA bind future paired comparisons. GitHub receives only summaries/manifests and bounded examples.

Generation latency is each saved synchronized `model.generate` call, excluding model loading and CPU decoding/serialization. Parallel wall time and GPU-device time are reported separately. Additional rankings/CCE/groups/CIs are `NO_DIRECT_PAPER_REFERENCE`; original four metrics alone have a direct [LETTER Instruments Table 1](https://arxiv.org/html/2405.07314v2) reference. A0/A1 model-size/cost differences cannot be attributed solely to SID; Shuffle requires its corresponding model's Normal baseline.
