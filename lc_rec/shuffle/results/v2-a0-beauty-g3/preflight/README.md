## 时间与正式计划

正式点估按 32 人实际 generation wall time/32 ×22,363 加实测严格装载。原 G3 单 V1 S3/S4 完整生成约 3.90 小时，装载约 159 秒。历史 Normal 的生成时间包含同进程 OFF。预跑样本的较长历史和硬件占用变化会影响外推。可先按每模式 4–6.5 小时安排窗口，并保留每项 8 小时硬上限与整组 36 GPU-device-hours。正式前刷新单卡空闲和可用显存。
预跑同分布预测文件外推四模式约 2.33 GB，另有原 Normal 0.400 GB。正式建议为原始输出、指标、压缩及临时展开共预留至少 10 GB 工作空间。预跑规模点估的文件大小受长历史和候选格式影响。
全量 CPU 单模式评价估计几十秒到数分钟，结合本轮 22,363 人 Normal 复算及原 G3 收尾。全量配对和独立复算计划为数分钟。按每项 1,200 秒、最终配对 2,400 秒设置 CPU 超时。正式归档／下载及从 ZIP 复核请另留 20–45 分钟，取决于最终完整预测大小、共享磁盘和 Windows 传输速度。
实际 GPU 预跑 812.994045 device-s，余 9987.005955。实际 CPU runner worker 260.875971 s，余 28539.124029，含失败、生命周期验证和导出。
