# 非作者审核 B

**评价、统计、执行与未提交计划通过。** 独立审核代理 `/root/audit_b` 读取冻结 A1 原始预测、本轮四模式原始预测、生产评价与统计产物、Git 对象和 new-server 持久 runner 记录。审核代码在本轮生产实现之外编写，未参与实验源码修改、远端作业提交或 GitHub 发布。ZIP 与 GitHub 发布的终末回读由独立交付回执记录。

| 核验对象 | 实际证据与结论 |
| --- | --- |
| 冻结 A1 Normal | 两个 SHA-256 固定分片，各 12,386 行。直接解析 495,440 个候选并按冻结 `row_idx` 复算，24,772×16 个 float64 指标单元及 16 项原精度均值与冻结归档精确一致。 |
| CCE | 直接依据 Instruments item→四码映射扩展候选的商品位置，目录外每次出现占一位，重复前置 SID 每次扩展，首个目标组内均匀计分。全目录 23 个碰撞组，冻结 Normal 中 122 名用户的目标处在碰撞组。 |
| 预跑候选 | 四组共 128 行、2,560 个候选。用 A1 tokenizer 词表重建逐码位合法集合，检查候选的完整 SID、实际 EOS/PAD、有限且可按 FP32 回转的原分数、生成顺序、稳定排序和目标标签。S2 的自然恒等全行 12005 和 17716 候选、排序及原精度分数均精确重合，S3a、S3b、S4 各零行。 |
| 80 条配对工程记录 | 独立按 PCG64 seed 20261113 复建 5,000×32 个共享采样索引，逐项精确一致。用每用户被抽中的次数重算 bootstrap 向量，再对已排序抽样结果独立线性插值。逐用户矩阵、配对差及 CSV 记录精确一致，draw means 最大浮点差 1.3877787807814457e-17，80 个区间的两端精确一致。 |
| Runner 与预算 | 16:31:15 UTC 直接在 zwlab-01 查验七个独立 job 请求、接受、认领、终态与实时清收。六个正常成功，一个预期超时夹具 exit −15，其标记子进程在独立 session 内先收 TERM 后收 KILL。所有 job 的 worker、supervisor 与任务工作组已清收。按 runner `started_at` 至 `ended_at` 保守计量，GPU 167.243993 device-seconds / 10,800，CPU 144.010992 worker-wall-seconds / 28,800。 |
| 正式计划与零提交 | 独立核对九阶段依赖、每模式 24,772 人和 495,440 候选、单卡、CPU 无 CUDA、固定输出位置和独立授权占位。按实际部署回执逐字节核验两个运行版本的 25 与 27 个 Git 对象。以真实计划再次执行本地 dry-run，发送请求零。独立服务器范围清点中，正式父任务、子任务、接受请求和预测均为零。 |
