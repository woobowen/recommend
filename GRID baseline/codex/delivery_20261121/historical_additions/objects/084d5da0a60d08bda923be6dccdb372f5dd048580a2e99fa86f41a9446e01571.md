## 下载方法

服务器直接访问 GitHub 曾超时；本机 Git 与 Git LFS 已可用。可先在本机单独目录克隆仓库，拉取 LFS 实体，再同步项目内容到上述项目根目录。请不要把只有 LFS 指针的 ZIP 当作数据。

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone --branch main https://github.com/woobowen/recommend.git recommend-restore
cd recommend-restore
git lfs pull --include="GRID baseline/original_assets/data/**,GRID baseline/experiments/**,GRID baseline/reconfigurations/**"
# 仅在要重算 Qwen 向量时补下载：
git lfs pull --include="GRID baseline/models/Qwen2.5-7B-Instruct/weight_parts/**"
```

以上是 Bash 写法；Windows PowerShell 设置变量用 `$env:GIT_LFS_SKIP_SMUDGE='1'`。这份清单只记录缺失项，不代表已下载。
